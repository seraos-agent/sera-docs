## 🛠️ Local Development

This documentation site is built with [Docusaurus](https://docusaurus.io/).

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Quick Start

1. **Clone repository:**
   ```bash
   git clone https://github.com/seraos-agent/sera-docs.git
   cd sera-docs
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run start
   ```
   Opens `http://localhost:3000` with hot-reloading.

4. **Build production bundle:**
   ```bash
   npm run build
   ```
